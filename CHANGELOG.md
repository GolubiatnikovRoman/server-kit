# CHANGELOG

## v1.0.0

Первый стабильный выпуск SERVER-KIT.

### Добавлено

- полностью русский интерактивный интерфейс;
- установка одной командой через `install.sh`;
- Semantic Versioning и отображение версии;
- проверка обновлений через GitHub Releases;
- обновление на конкретный тег релиза;
- SHA-256 проверка файлов при установке/обновлении релиза;
- резерв предыдущей версии SERVER-KIT перед обновлением;
- двухэтапная безопасная смена SSH-порта;
- временное одновременное прослушивание старого и нового SSH-портов;
- ручное подтверждение успешного нового SSH-соединения перед закрытием старого порта;
- rollback незавершённой смены SSH-порта;
- отключение SSH-пароля только при наличии ключа текущего пользователя;
- настройка `PermitRootLogin`;
- UFW с защитой текущего SSH-порта;
- Fail2ban и SSH jail;
- unattended-upgrades;
- управление APT-обновлениями;
- мониторинг CPU/RAM/Swap/дисков/процессов/портов/сети;
- управление systemd-службами;
- установка Docker только после подтверждения пользователя;
- управление Docker-контейнерами, логами, stats и очисткой;
- управление Screen-сессиями;
- резервные копии SSH/UFW/Fail2ban;
- быстрая и полная диагностика;
- динамический MOTD SERVER-KIT;
- команды `version`, `check`, `check-update`, `update`, `backup`, `uninstall`.
