# CHANGELOG

## v1.2.0

Русификация терминального интерфейса и управление приветствием при SSH-подключении.

### Изменено

- основные заголовки, состояния служб и подсказки меню переведены на русский язык;
- приглашения ввода в главном и вложенных меню унифицированы: «Выберите пункт:»;
- сохранены оформление, цветовая индикация, нумерация и логика существующих меню;
- приветствие SERVER-KIT при SSH-подключении сохранено без изменения формата.

### Добавлено

- возможность скрыть стандартную сводку Ubuntu при SSH-подключении, сохранив приветствие SERVER-KIT;
- возможность восстановить прежние права скриптов Ubuntu MOTD;
- предложение восстановить стандартный MOTD при удалении SERVER-KIT.

## v1.1.0

Обновление интерфейса и логики управления SERVER-KIT.

### Изменено

- новый dashboard-интерфейс главного меню в стиле TUI-lite;
- адаптивная раскладка для широких и узких терминалов;
- единая цветовая семантика статусов;
- state-aware меню: действия установки скрываются, если компонент уже установлен;
- SSH-меню показывает только релевантные действия для текущего состояния;
- UFW проверяет наличие разрешающего правила для текущего SSH-порта;
- Fail2ban проверяет не только службу, но и активность SSH jail;
- Docker различает состояния RUNNING, STOPPED, ERROR и NOT INSTALLED;
- Docker показывает количество запущенных/всех контейнеров и образов;
- Screen, MOTD, btop/htop и security-updates получили динамические действия;
- Backup скрывает недоступные операции восстановления;
- Diagnostics учитывает состояние UFW, Fail2ban и Docker;
- Services не предлагает запускать уже запущенное или включать уже включённое;
- число APT-обновлений кэшируется на 60 секунд;
- исправлен расчёт ширины рамок при ANSI-цветах;
- установка из ветки main всегда использует актуальный main.

## v1.0.0

Первый стабильный выпуск SERVER-KIT.

### Добавлено

- полностью русский интерактивный интерфейс;
- установка одной командой через `install.sh`;
- Semantic Versioning и отображение версии;
- проверка обновлений через GitHub Releases;
- обновление на конкретный тег релиза;
- SHA-256 проверка файлов при установке/обновлении релиза;
- резерв предыдущей версии SERVER-KIT перед обновлением;
- двухэтапная безопасная смена SSH-порта;
- временное одновременное прослушивание старого и нового SSH-портов;
- ручное подтверждение успешного нового SSH-соединения перед закрытием старого порта;
- rollback незавершённой смены SSH-порта;
- отключение SSH-пароля только при наличии ключа текущего пользователя;
- настройка `PermitRootLogin`;
- UFW с защитой текущего SSH-порта;
- Fail2ban и SSH jail;
- unattended-upgrades;
- управление APT-обновлениями;
- мониторинг CPU/RAM/Swap/дисков/процессов/портов/сети;
- управление systemd-службами;
- установка Docker только после подтверждения пользователя;
- управление Docker-контейнерами, логами, stats и очисткой;
- управление Screen-сессиями;
- резервные копии SSH/UFW/Fail2ban;
- быстрая и полная диагностика;
- динамический MOTD SERVER-KIT;
- команды `version`, `check`, `check-update`, `update`, `backup`, `uninstall`.
